# xagent-sdk-python

Python client SDK for the [xAgent](https://github.com/xorbitsai/xagent) HTTP v1 API.

> **Status**: 0.1.0 — early access. The v1 backend contract is frozen,
> but the SDK surface may evolve through the 0.x series.

## Development

```bash
uv sync --group dev
uv run pre-commit install
uv run pytest
```
